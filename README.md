Invoice Management & PDF Generator with WhatsApp IntegrationA feature-rich Desktop Application built using Java Swing (GUI) to streamline the invoicing process. This system automates the creation of professional itemized bills, generates secure PDF receipts using the iText library, and automates the sending process via WhatsApp using the Java Robot Class and Web Links.🚀 Key FeaturesDynamic Billing Structure: Input Customer details, Product Name, Unit Price, and Quantity effortlessly.Automated Calculations: Instantly updates Total Price, applies custom Discount (%) rates, and computes the final Payable Total.Automated PDF Generation: Uses the iText Library to compile and export structured, clean PDF invoices programmatically.Smart WhatsApp Automation:Generates custom WhatsApp Web links containing invoice details.Utilizes the Java Robot Class to automate keyboard and mouse actions, seamlessly sending the invoice notification without manual copying.Modern Dark UI: Sleek, user-friendly, and interactive dark-themed dashboard.🛠️ Tech Stack & LibrariesLanguage: JavaGUI Framework: Java Swing / AWTPDF Generation: iText PDF Library (Core)Automation: Java java.awt.Robot Class⚙️ How It WorksAdd Items: Enter product fields and click "Add to Bill" to populate the structured item table.Apply Discounts: Insert the discount rate to instantly view the final payable amount.Generate & Send: Click "Generate Invoice and send to WhatsApp" to trigger:The iText engine creating a local copy of the PDF invoice.A web browser launching the official WhatsApp Web API link.The Robot Class simulating keystrokes to auto-send the text payload to the specified WhatsApp number.
